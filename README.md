# martian-map

## Советы по Codeberg, Git

1. В первую очередь, включите уведомления на почту, и убедитесь что на телефоне/ПК
включены уведомления из почты

Если этот пункт выполнен, 80% успеха обеспечено (не хотелось бы писать в личку
по каждому чиху)

2. Коммиты пишем в формате `тип: что сделал` (`feat`, `fix`, `docs`, `ref`,
   `chore`, `style`...). Писать что сделал и описание желательно на русском.
   Формат не строгий. \
   Если коммит сложный или неочевидный, объясните в теле коммита, зачем он.
3. Работаем в отдельных ветках, в `main` вливаем только рабочий код
4. Задачи и спорные решения обсуждаем в Issues или в PR, а не в личке
5. Если ждёте ревью или заблокированы, сразу пингуйте нужного человека
   через `@username`
6. Если не успеваете со своей частью, скажите заранее и передайте задачу

## Использование ИИ

Мы договорились, что использовать ИИ разрешено и приветствуется,
однако при применении ИИ, **необходимо вести отчет о всех запросах**.
Это требуется по регламенту хакатона

Запрос должен быть в комментарии рядом со сгенерированным фрагментом кода

Чтобы ваш запрос не потерялся, обязательно добавьте в комментарий слово "Prompt",
это значительно упростит поиск всех запросов
(поиск будет осуществляться, вероятно, мною через ripgrep).

Это поможет при составлении итогового отчёта

Например:

```html
<!--
Deepseek V4.1 Flash
Prompt: give me simple login html + css, no backend yet
-->

<!DOCTYPE html>
<html lang="en">
<head>
  ...
</html>
```

При правке сгенерированного кода, комментарий остаётся над блоком, даже
если код потом отредактирован
